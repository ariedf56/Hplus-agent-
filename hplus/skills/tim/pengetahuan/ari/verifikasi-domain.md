# Verifikasi domain (anti-phishing) 🛡️

Sebelum `kredensial.py isi`:
1. Bandingkan domain di address bar dengan `situs` yang tercatat — harus PERSIS (bukan mirip).
2. Waspadai redirect: bila setelah buka terjadi redirect ke domain lain → BERHENTI.
3. Cek keanehan: sertifikat tidak valid, tampilan login berbeda dari biasa, pop-up meminta kredensial ulang → laporkan sebagai ancaman ke Komandan.
